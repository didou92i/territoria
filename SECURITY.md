# Signaler une faille de sécurité

TerritorIA traite des données de collectivités : une faille peut exposer des données personnelles. Merci de la signaler
**en privé**, jamais dans un ticket public.

- **Comment** : onglet **Security** du dépôt GitHub, puis **Report a vulnerability** (signalement privé de GitHub).
  Seul le mainteneur voit le signalement. Sans compte GitHub, utilisez le formulaire de contact donné dans les
  [mentions légales du site](https://territoria.ovh/#mentions), en choisissant l'objet « Sécurité ».
- **Quoi** : la version concernée (étiquette ou commit), le système (Windows, macOS, Linux), les étapes pour reproduire
  et l'effet constaté. N'envoyez **aucune donnée réelle** de collectivité : des données fictives suffisent.
- **Ensuite** : le mainteneur accuse réception, puis publie la correction dans une nouvelle version, en citant le
  signalement si vous le souhaitez.

Les installations à jour sont les seules à recevoir des correctifs : voir « Mise à jour » dans le
[`README`](README.md).
